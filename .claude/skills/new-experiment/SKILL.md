# 새 실험 폴더 만들기

1. 사용자가 말한 주제를 짧은 영문 kebab-case 이름으로 바꾼다. 예: `fastapi-basics`
2. `experiments/<이름>/` 폴더를 만든다. 이미 있으면 덮어쓰지 말고 사용자에게 알린다.
3. 그 안에 `README.md`를 아래 템플릿으로 만든다.

```markdown
# <주제>

## 목표
무엇을 배우거나 확인하려는가 (한두 문장)

## 진행 기록
- [ ] 1단계:

## 배운 점
(실험 후 작성)

## 막혔던 점 / 에러
(원인과 해결 방법 포함)
```

4. 첫 단계는 가장 작은 동작 예제로 제안하고, 코드를 쓰기 전에 계획을 먼저 보여준다.
5. 완료되면 `배운 점`을 사용자와 함께 채운다.
